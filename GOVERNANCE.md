# Governance

C interposer for Steam CEF scaling on Wayland. The project is currently maintained by [@IanHollow](https://github.com/IanHollow), who holds repository administration, security settings, and release authority. No other person currently has privileged repository access.

Propose changes and report ordinary defects through GitHub issues and pull requests. Significant changes should be discussed in an issue before implementation. The maintainer decides the project roadmap and merges reviewed changes.

Before granting a collaborator elevated repository or release access, the maintainer reviews their contribution history and the responsibilities they need to perform, grants the least privilege needed, and periodically rechecks access. A second independent reviewer is required before claiming OSPS Baseline Level 3; until one is available, no Level 3 claim is made.
