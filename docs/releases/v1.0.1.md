# Steam CEF scale override v1.0.1

This is the first source release. It contains no prebuilt shared library. Build
it locally or through Nix for the Linux system that runs Steam.

## Changelog

- Add an opt-in CEF scale override limited to the `steamwebhelper` process.
- Validate scale values and initialization results, and remain inert when the
  required Steam symbol is unavailable.
- Add Meson builds, mock CEF behavior tests, sanitizers, ELF hardening checks,
  and Nix packaging.

## Compatibility and support

The supported use is Linux x86_64 with a Steam client that exports the tested
CEF symbols. Valve does not provide this as a stable API, so compatibility may
change with a Steam update. Security reports for this source release are
accepted through 2027-03-24. Fixes may ship in a newer version; this archive
will not be changed. See [SECURITY.md](../../SECURITY.md) for private reporting.

## Build and verification

Run `meson setup build -Dtests=true`, `meson compile -C build`, and
`meson test -C build --print-errorlogs`, or run
`nix build .` from the extracted archive. The release
includes a SHA-256 checksum, a release manifest, and a Sigstore SLSA provenance
bundle for the exact source archive. Follow
[release verification](../security-and-releases.md#verify-a-source-release)
before using the archive. The Nix package remains available through
[`nixpkgs-personal`](https://github.com/nix-forge/nixpkgs-personal).

The `v1.0.0` tag did not publish a release because provenance verification
failed. It remains as an unreleased tag; this version contains the corrected
release verification workflow.
