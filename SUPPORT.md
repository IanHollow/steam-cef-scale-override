# Support

This project is maintained on a best-effort basis. GitHub issues are the public support channel for installation, usage, and defects. Use GitHub private vulnerability reporting for suspected security defects.

The current `main` branch is the active development line. Security reports
for the `v1.0.0` source release are accepted through 2027-03-24. Fixes may
ship in a newer version; published source archives are immutable and receive
no in-place changes. No earlier version has an implied support window. See
[v1.0.0 release notes](docs/releases/v1.0.0.md) for platform limits.
