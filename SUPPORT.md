# Support

This project is maintained on a best-effort basis. GitHub issues are the public support channel for installation, usage, and defects. Use GitHub private vulnerability reporting for suspected security defects.

The current `main` branch is the only supported development line. No release series or security-update window exists yet. When releases begin, each release will state its supported platforms, support period, end-of-support date, and migration guidance. Old versions receive no implied security support.
